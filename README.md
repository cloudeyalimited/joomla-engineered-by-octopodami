# Joomla Engineered by OCTOPODAMI® (JEBO)

With [Joomla](https://www.joomla.org/) Engineered by OCTOPODAMI® (JEBO), you can launch a Joomla stack pre-configured for reliability, maintainability, performance, and security.

Our engineers built this 1-Click Amazon Machine Image (AMI) for rapid deployment; a new server is usually ready in about 10 minutes on Amazon Web Services.

Instead of spending countless hours learning the details of a Joomla build, we've packaged our stack with everything you need to publish content on the world's leading cloud platform.

## Features

Joomla Engineered by OCTOPODAMI® (JEBO) uses the following technologies:

1. **Joomla 6**: Modern, open-source content management system
2. **Nginx**: Fast, lightweight web server with high performance
3. **Amazon Linux 2023**: AWS-optimised Linux distribution with enhanced security
4. **PHP 8.4**: Modern PHP with improved performance and long-term support
5. **MariaDB 12.3**: High-performance MySQL-compatible database
6. **Instance ID unlock**: Every server stays closed until you enter its EC2 instance ID
